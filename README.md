One original one-line dad joke — an entry for make.fun's
"The One-Liner Groan-Off" bounty. The entry is a single line, at most
140 characters, the kind of pun a dad delivers at the dinner table:

> I asked my mirror for an honest opinion, and it said I was looking a little reflective today.

## Run

```sh
node main.ts
```

Writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `./output/entry.txt`),
a single line with no trailing newline.
